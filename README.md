# GrowthOS

Internal multi-brand acquisition and landing-page operating system.

GrowthOS is designed to let the team create, edit, publish, track, test, and optimize high-performance acquisition landing pages across SkillUp, Jalwa, Game Arena, Bizly Medan, and future products without routine developer involvement.

## Product principles

- Schema-driven landing pages, not arbitrary HTML/CSS/JS.
- One reusable Next.js renderer across any number of brands.
- Mobile-first performance and technical SEO are release requirements.
- Campaign, offer, creative, page, variant, and conversion attribution are first-class concepts.
- AI generates structured drafts and suggestions; humans control publication.
- Keep infrastructure simple until scale proves otherwise.
